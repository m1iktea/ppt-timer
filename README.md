# PPT 倒计时

PowerPoint / WPS 开始放映时，讲者屏幕角落自动出现倒计时（默认 5 分钟），到点自动进入下一轮重新倒数，退出放映自动消失。透明底黑字，不挡内容。

## 需求背景

讲 PPT 时讲者需要掌握时间，但不希望观众看到计时，也不希望为计时多做任何操作。具体诉求：

| 诉求 | 说明 |
|---|---|
| 自动启动 | 开始放映即开始计时，不弹窗、不点按钮 |
| 倒计时 | 默认 5 分钟，时长可配置（改一次长期生效） |
| 循环 | 一轮到点后自动进入下一轮，持续提醒讲者节奏 |
| 自动关闭 | 退出放映，计时窗随之消失 |
| 观众不可见 | 接投影时计时只出现在讲者自己的屏幕 |
| 环境 | Windows，以 **WPS** 为主，兼容 PowerPoint；客户端不装任何依赖 |

### 为什么不用原生功能

| 原生方案 | 不满足的地方 |
|---|---|
| PowerPoint 演示者视图计时器 | 只有正计时，不能倒计时、不能设时长；WPS 无对应能力 |
| 排练计时 | 只记录用时，不提醒 |
| 动画做倒计时（擦除进度条） | 动画属于单页，翻页即重置 |
| AppSource 计时器加载项 | 需插入到某页，跨页不连续；企业环境常无法安装 |
| Windows 时钟计时器 | 不能跟随放映自动启停 |

### 技术选型

- **Go + 原生 Win32 API**：在 macOS 上 `GOOS=windows` 直接交叉编译出单个 exe（约 2 MB），客户端零依赖，无需 cgo
- 未选 AutoHotkey：编译出的 exe 客户端同样免安装，但编译器 Ahk2Exe 只能在 Windows 上运行
- 未选 PowerShell：需要处理执行策略，启动有控制台黑框
- 未选 VBA 加载项（.ppam）：需放开宏信任，全屏放映时窗体易被遮挡，且不支持 WPS

## 工作原理

- 每 500ms 枚举顶层窗口，判断是否在放映：
  - PowerPoint：放映窗口类名 `screenClass`
  - WPS（`wpp.exe` / 整合版 `wps.exe`）：该进程存在**无标题栏、非最大化、铺满整块显示器**的窗口
- 连续 3 次（1.5 秒）检测不到放映才判定退出，避免切换时窗口短暂消失导致误关
- 计时窗：置顶、不抢焦点、鼠标穿透（不影响操作 PPT）、不出现在任务栏；用色键实现透明背景
- 位置固定在**主屏**工作区角落：扩展模式下主屏即讲者的笔记本屏，放映在投影上
- 每次开始放映重读配置，改 ini 无需重启程序

## 使用

1. 选对应版本：普通电脑用 `ppt-timer-amd64.exe`，ARM 笔记本（骁龙本 / Surface Pro X）用 `ppt-timer-arm64.exe`
2. 放到固定目录，双击运行（无窗口，后台常驻，重复启动只保留一个实例）
3. 开机自启：`Win+R` 输入 `shell:startup`，把 exe 的快捷方式拖进去

首次运行会在 exe 同目录生成 `ppt-timer.ini`：

```ini
minutes=5           ; 每轮倒计时分钟数，可写小数如 2.5
position=top-right  ; top-right / top-left / bottom-right / bottom-left
```

下次开始放映即生效。启动时配置有误会弹窗提示并退出；运行中改错则沿用上次的正确配置（`--debug` 日志里有记录）。

## 接投影仪

- 必须用**扩展**模式（`Win+P` → 扩展），计时窗只出现在主屏
- 复制模式下两块屏内容相同，观众会看到计时窗
- 放映设置里让幻灯片放映在投影仪上，演示者视图在笔记本上

## 退出程序

运行 `ppt-timer-amd64.exe --quit`，或任务管理器结束进程。

## 不生效时排查

先 `--quit` 结束正在运行的实例，再用 `--debug` 启动：

```
ppt-timer-amd64.exe --debug
```

开始放映后等几秒再退出，查看同目录的 `ppt-timer-debug.log`，里面记录了 PPT/WPS 各窗口的类名、尺寸、样式和判定结果。

## 已知限制

- 黑字在深色背景（如演示者视图）上可能看不清
- WPS 全屏阅读文档（非放映）也可能被识别为放映
- exe 未做代码签名，首次运行 SmartScreen 会拦截，点「更多信息 → 仍要运行」；杀毒软件误报需加白名单
- 尚未在真实 Windows 环境完成验证

## 开发

```bash
go test -race -cover ./...   # 倒计时与配置解析的单元测试，可在 macOS 上跑
./build.sh                   # 交叉编译 amd64 / arm64，产物在 dist/
```

| 文件 | 职责 |
|---|---|
| `main.go` | 入口、单实例、`--quit` / `--debug` |
| `timer.go` | 计时窗创建、绘制、放映状态机 |
| `detect.go` | 放映窗口检测 |
| `countdown.go` | 循环倒计时计算 |
| `config.go` | ini 配置解析与校验 |
| `debug.go` | 调试日志 |
| `win32.go` | Win32 API 声明 |
